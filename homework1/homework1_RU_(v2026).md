# Домашнее задание №1

## Задание
Необходимо создать и разметить собственный набор данных, состоящий из изображений. Набор содержит **не менее 3 классов** и **не менее 100 экземпляров** каждый. Изображения можно скачать из интернета или объединить несколько существующих датасетов. На собственном датасете обучить модель. Создать web-приложение для классификации изображений полученного набора данных. Использовать аугментацию данных, регуляризацию, перенос обучения.

## Контрольные вопросы
1. Структура набора данных, аугментация данных.
2. Перенос обучения, дообучение.
3. Архитектура сверточной нейронной сети.

## Часть 1. Сбор и подготовка набора данных

### Загрузка изображений

Существует несколько способов получения изображений для датасета. Выберите наиболее удобный для вас:

**Вариант 1. Ручной сбор**

Найдите изображения в поисковых системах (Яндекс.Картинки, Google Images) по тематике ваших классов и скачайте вручную, разложив по трем отдельным папкам.


**Вариант 2. Использование браузерного расширения**

Установите одно из расширений для массовой загрузки изображений, например:
- [Image downloader - Imageye](https://chrome.google.com/webstore/detail/image-downloader-imageye/agionbommeaifngbhincahgmoflcikhm?hl=en)
- [Image Downloader](https://chrome.google.com/webstore/detail/image-downloader/cnpniohnfphhjihaiiggeabnkjhpaldj?hl=en)

Порядок действий (пример для выбранного расширения):
1. Выполните поиск картинок в поисковой системе
2. Откройте расширение
3. Укажите необходимые параметры (тип файла, размер и т.д.)
4. Выберите нужные изображения и скачайте

> **Важно:** Ссылки и интерфейсы расширений могут меняться. Актуальную информацию уточняйте на момент выполнения работы.

![image](images.png)


**Вариант 3. Использование Python-библиотек**

Существуют библиотеки для программного скачивания изображений, например:
- `yandex-images-download` (для Яндекс.Картинок)
- `google-images-download` (для Google Images)
- Другие аналогичные инструменты

Ниже приведен пример использования (актуальность команд и параметров уточняйте в документации библиотеки):

```bash
# Пример для yandex-images-download (требуется ChromeDriver)
yandex-images-download Chrome --keywords "кошка, собака, птица" --limit 100
```

> **Обратите внимание:** Библиотеки и API поисковых систем могут изменяться. Рекомендуется проверять актуальность инструментов непосредственно перед выполнением работы.


### Валидация изображений

После загрузки изображений **обязательно** выполните ручную проверку:
- Удалите дубликаты (одинаковые изображения)
- Удалите изображения, не соответствующие тематике класса
- Удалите битые или некорректные файлы

Требуется оставить не менее 100 качественных изображений на каждый класс.

## Часть 3. Web-приложение на FastAPI + Jinja2

В этой части необходимо создать веб-приложение для классификации изображений с использованием обученной ONNX-модели.

### Используемый стек

- **FastAPI** — веб-фреймворк для создания API и веб-приложений
- **Jinja2** — шаблонизатор для генерации HTML-страниц
- **ONNX Runtime** — для выполнения инференса модели
- **Uvicorn** — ASGI-сервер для запуска приложения

Подробная инструкция по созданию веб-приложения вынесена в отдельный документ:

👉 **[Ссылка на инструкцию по созданию FastAPI + Jinja2 приложения (API-Jinja/)](/homework1/API-Jinja/FastApi-Jinja-instruct.md)**

### Основные шаги:

1. **Установка библиотек:**
```bash
pip install fastapi==0.115.0 starlette==0.41.0 jinja2==3.1.4 python-multipart onnxruntime pillow
```

2. **Создание структуры проекта:**
```
project/
├── main.py                 # Основной файл приложения
├── templates/
│   └── index.html          # HTML-шаблон
├── media/
│   ├── images/             # Загруженные изображения
│   └── models/             # ONNX-модель
│       └── model.onnx
```

3. **Реализация приложения:**
   - Загрузка ONNX-модели
   - Предобработка изображений
   - Выполнение инференса
   - Отображение результата

4. **Запуск приложения:**
```bash
uvicorn main:app --reload
```

### Запуск и тестирование

После запуска приложения:
- Откройте браузер по адресу `http://127.0.0.1:8000`
- Загрузите тестовое изображение
- Проверьте корректность классификации
